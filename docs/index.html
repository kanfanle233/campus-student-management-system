使用说明

用三分钟熟悉 CampusFlow 的核心操作。

01

浏览数据

从左侧进入“学生档案”，在搜索框输入姓名或学号，也可以按班级、性别筛选。

02

维护档案

点击“新增学生”填写六项资料。每条记录都可以编辑或删除，学号不能重复。

03

保存与迁移

所有修改会自动保存到当前浏览器。数据中心支持 CSV 导入导出，方便课堂演示和备份。

✦

这是一个静态演示版本

页面发布在 GitHub Pages 上，浏览器会用 localStorage 保存数据。它不连接服务器；清理浏览器站点数据会删除演示中的修改，点击“重置演示数据”也可以恢复初始记录。
